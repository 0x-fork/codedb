# CodeDB 0.2.5855

Release branch based on `4eaca89` (the merged 0.2.5854 branch).

## Watcher work and MCP startup

[Issue #748](https://github.com/justrach/codedb/issues/748) reproduces sustained
macOS CPU use when unrelated files churn in a repository beyond the watch budget.
Coalesce native events for 100ms, reconcile affected paths, and verify overflow
contents on a separate two-second cadence. Periodic hashes still detect
same-metadata rewrites. Directory audits and one watcher per MCP process remain.
See [the reproduction and measurements](../watcher-748.md).

[PR #747](https://github.com/justrach/codedb/pull/747) adds a predicate reorder to
avoid unrelated watch-registration lookups and optional lazy MCP startup.
`CODEDB_LAZY_MCP=1` leaves unused default projects idle until the first code
request. Eager startup remains the default; the first lazy query can wait up to
30 seconds before returning a retry error. See [setup and rollback](../mcp.md#experimental-lazy-startup).

## Updates and README

[PR #745](https://github.com/justrach/codedb/pull/745), merged after the previous
release tag, addresses [#742](https://github.com/justrach/codedb/issues/742).
Fallback workers return uncached 503 responses when release lookup fails instead
of fabricating an old version. The CLI distinguishes stale automatic metadata
from an explicit downgrade request and preserves downgrade protection.

The README now includes task-oriented navigation and matching light/dark
Codegraff illustrations. [Palette and generation prompts](../images/README.md).
